# WP paper style

Papers live in the project vault, outside this repo; the
repo stays code-only. Rules set 2026-07-30. Each paper's vault README is
the per-paper authority — check it before drafting.

- **Framing is a per-paper decision, not a series rule.** WP1 is a readable paper
  with machinery demoted to appendices; WP2 is a model spec, assumptions first. The
  README says which kind each paper is.
- **The reader is a smart high schooler.** One-line rules, plainly named dials, no
  machinery in the main body.
- **Abstracts summarize in words only.** No numeric results; ~100 words.
- **No parenthetical asides in prose.** If it matters, own sentence; if not, cut.
  Citation commands and mathematics are exempt.
- **No invented vocabulary.** Standard literature terms or engine config fields;
  plain descriptive English over coinages — "amplification", never "the flood".
- **Counterfactual-ordering claims only, never prediction.**
- **Parameters typed:** anchored / tuned-for-legibility / arbitrary-but-swept.
- **Predictions committed before sweeps run; mismatches reported as findings, never
  retuned away.**
- **`%% VERIFY` on memory-written bib entries** — check against publisher pages
  before the draft circulates; verified entries name their verification date.
- **No test-count citations in external text.**
- **Every figure and inline number regenerates from committed experiment artifacts**
  (`experiments/CLAUDE.md`); nothing hand-drawn.
