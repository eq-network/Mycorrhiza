# WP1 — Where Does the Money Go?

Working paper 1 of the lab series: a stock-flow-consistent toy-model study of
AI/automation capital, wealth concentration, and its defenses, across the
engine's economy register (`compute_economy`, `io_economy`, and the
`capital_economy` fork specified here).

- Build: `latexmk -pdf main` (MiKTeX; aux files are gitignored).
- `refs.bib` — curated references. Entries marked `%% VERIFY` were written from
  memory and must be checked against `lit/` metadata before the final build.
- `lit/` — literature-sweep artifacts (BibTeX + positioning notes per thread;
  produced by the lit-review pipeline, PaperPipeline side).
- `figures/` — every figure regenerated by `experiments/wp1_economy/figures.py`
  from `results.json` only; nothing hand-drawn.
- Design record: eq-network `DESIGN-LOG.md` (2026-07-29 entries) and the
  approved plan (`hashed-discovering-sunset`).

House rules that bind this paper: counterfactual-ordering claims only, never
prediction; every parameter typed anchored / tuned-for-legibility /
arbitrary-but-swept; analytical predictions committed before sweeps run; no
test-count citations in external text.
